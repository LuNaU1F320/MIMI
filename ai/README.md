# Artificial Intelligence

The AI domain owns optional asynchronous intelligence features for MIMI.

## Current Status

This folder is a placeholder for future AI experiments and reusable tools. No production AI code has been added yet.

## Expected First Slice

- Consume exported session events
- Estimate simple engagement metrics
- Produce non-blocking recommendation reports
- Document how recommendations could be promoted through the backend later

## Integration Note Requirement

AI features must state whether they are offline, asynchronous, or live advisory. They must not block real-time controller input or Unreal content execution.
